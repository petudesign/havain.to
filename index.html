How much does a shelf map help with date checks?

One dairy shelf with 40 sections, four weeks, the same customers and the same staff time. Four ways of finding near-expiry products, each run 200 times.

Mostly placeholder numbers. Published data does not exist for the two parameters that matter most (time on the shelf, time a check takes). Some values are calibrated from my own years in a hypermarket dairy department; the rest are assumptions. Read the results as a comparison between strategies, not as a forecast of real waste.

RouteToday’s practice. Date checks morning and evening, walking the shelf in order as far as time allows. The next shift often starts over.
Manual mapThe 2025 concept. Staff write down the earliest date per section; the map sets the order.
Map + 2D dataDates come from scanning 2D codes. Every near-expiry unit gets a label.
Map + 2D + salesSame data plus the sales rate. Only units that would not sell in time get a label.
