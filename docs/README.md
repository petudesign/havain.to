## Conventions

- Dates as YYYY-MM-DD.
- Every number in the case must trace back to a source in `research/` or to a simulation run logged in `build-log.md`.
- Mark anything unverified as **unverified**.

## How to read the numbers

- **Model values are assumptions and averages, not facts about any one store or person.** Stores differ, products differ, and people differ even more: a new employee can be quick and careful or slow and unsure.
- **Prefer ranges to single values.** When a value is a guess, run the model over a plausible range and report whether the conclusion holds across it. A conclusion that only holds for one guessed value does not go in the case.
- **Say what the model leaves out** next to every result (e.g. learning over time, people with very different skills on the same shelf).
- **In the case,** write "in the model" or "under these assumptions", and show the range, not a single precise-looking number.
