# Interviews

Plan: 3–5 short interviews (20–30 min) with current or former grocery store staff who do date checks.

Store anonymised notes here as `YYYY-MM-DD-p1.md`, `p2.md`, … No names, store names or locations.

The interview guide is still to be written. Its second job is to check the simulation's assumptions (time per check, how shifts hand over, how often items are missed), so it should be written once the model's parameter list is stable.
